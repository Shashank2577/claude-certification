Questions

Fair questions, straight answers.

Is this official?

No. This is an independent, unofficial study aid. It is not affiliated with, sponsored by or endorsed by Anthropic. For the authoritative exam format, domains, weights and policies, use the official exam guide.

Are these real exam questions?

No, and that is on purpose. There are no exam dumps here. Every question is original, written from the public documentation and checked by two independent reviewers against the official docs. The goal is to make you good at the judgment calls, not to memorise answers.

Is it really free?

Yes. Lessons, explainers, practice questions, flashcards and mock exams are free. You sign in only so your progress, streaks and readiness score are saved.

I’m not an engineer. Can I still use it?

Yes. Each lesson starts with a plain-English explanation before the technical detail, and the interactive explainers show how the pieces fit together visually. Product managers, solution consultants and team leads use it to understand how Claude systems are designed.

Which exam should I start with?

Foundations covers the core building blocks: agents, tools and MCP, Claude Code, prompting and context. Professional builds on that with solution design, evaluation, governance and lifecycle. If you are unsure, start with Foundations; most of it carries straight over.

How long does preparation take?

Pick a 3, 7 or 14-day plan depending on how much you already know. If you have built with Claude before, the shorter plans focus on gaps. If not, the 14-day plan builds things up from the basics.

Can I see the code?

Yes. The source is public on GitHub. Issues and corrections are welcome, especially if you spot something that has changed in the docs.
